1. 体液占体重的60%[^3]，包括细胞内液和细胞外液，细胞内液占体液的2/3（占体重的40%），细胞外液占体液的1/3（占体重的20%）[^31]
2. 细胞外液包括血浆、组织液、淋巴液、脑脊液[^17]，其中血浆占细胞外液的1/4（占体重的5%）[^16]，组织液占细胞外液的3/4（占体重的15%）[^27][^32]
3. 各部分体液因细胞膜、毛细血管壁或淋巴管壁隔开[^21]，因而有较大的成分差异：
   1. 例如**细胞内液**以K^+^和HPO~4~^2-^较多[^20]，而**细胞外液**以Na^+^、Ca^2+^和Cl^-^较多[^34]
   2. 血浆比组织液含有较多的蛋白质[^6][^28]

4. 各部分体液可相互沟通：
   1. 例如细胞内K^+^向细胞外流，细胞外Na^+^向细胞内流
   2. 血浆是沟通各部分体液，并与外环境进行物质交换的重要媒介，因而**血浆是体液中最活跃的部分**[^33]



## 2. 内环境

[[⭐️考研/小红书/生理学/1~100/02#02|题1]]、[[小红书/生理学/1~100/⭐️03#03|题2]]、[[小红书/生理学/1~100/⭐️04#04|题3]]、[[小红书/生理学/1~100/⭐️05#05|题4]]、



1. 细胞外液是细胞赖以生存的环境，称为机体的内环境[^14][^23][^29]
2. 内环境的理化特性和液体成分保持相对稳定的状态称为内稳态，这是一种**动态平衡**[^38]
   1. pH约7.35~7.45[^9][^18][^19]
   2. 温度约36~37°
   3. 渗透压约290~310mmol/L[^7][^25]
   4. Na^+^约135~150mmol/L
   5. K^+^约3.5~5.5mmol/L[^19][^26] ^6lspfx
   6. Ca^2+^约2.25~2.75mmol/L
3. 理化性质：渗透压、温度、pH值、液体成分等
4. 内环境的稳态不是静止/固定不变，而是**动态平衡、相对恒定**，其理化性质可在狭小范围内变动：如pH值7.35\~7.45、K^+^3.5\~5.5mmol/L、Na^+^135\~150mmol/L、渗透压290\~310mmol/L
5. 内稳态是稳态的其中一种类型，稳态泛指体内从细胞和分子水平、器官和系统水平到整体水平的各种生理功能活动保持相对稳定的状态，**所以稳态不仅仅限于内环境的稳态**，内环境的稳态只是稳态中的一种类型
6. 稳态的维持是机体**自我调节**的结果[^8]，稳态是机体维持正常生命活动的必要条件[^24]，最主要依靠**负反馈**控制系统，其通过调定点进行调节，是机体维持正常生命活动的必要条件[^15]
7. 人体内环境及其稳态是**长期生物进化**的结果



## 3. 小结

1. 细胞外液占体液的1/3（占体重的20%），包括血浆（占体重的5%）、组织液、淋巴液、脑脊液，以血浆最活跃 ^gr3bsv
2. 各部分体液彼此隔开又可相互沟通，因而有较大的成分差别[^12]
3. 机体的内环境指**细胞外液**，其理化特性和液体成分保持相对稳定的动态平衡状态称为内稳态，这是稳态的类型之一
4. 机体通过**自我调节**维持稳态，以便维持正常生命活动



## 4. 易错

1. 要区分相应体液是占哪些部分的多少，比如组织液是占细胞外液的3/4，则应该占体液的3/4×1/3＝1/4，占体重的1/4×60%＝15%
2. 血液中的血浆才是细胞外液，血细胞不是
3. 在《生理学》中认为消化液、汗液、尿液、泪液都不属于细胞外液，因它们与外环境相通，《生理学》所认为的细胞外液是细胞直接接触并赖以生存的环境（即内环境）[^22][^37]
